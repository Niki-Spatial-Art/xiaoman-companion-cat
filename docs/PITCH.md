# 一分钟项目介绍

大家好，我想做一只叫“小满”的陪伴猫。

它会趴在茶几或床头。你摸摸它，它便轻轻呼噜；你说起今天吃了什么，它陪你聊聊家常。

我希望人们愿意给它留一个位置，偶尔摸摸它、和它说说话，在日常里多一份小小的牵挂。

这次比赛，我计划以地瓜 RDK 为核心，完成触摸回应、简短对话和生活提醒原型。语音先跑通普通话，再试上海话，让声音更贴近熟悉的生活。

我会负责产品、形态与交互设计，希望和硬件、软件伙伴一起，把这只小猫做出来。

**小满，有伴的日子，刚刚好。**

## 计划演示流程

1. 展示桌面猫形与柔软接触区，说明产品构想。
2. 摸头，触发呼噜或微动作。
3. 按猫爪，进行一轮家常对话。
4. 提出“一分钟后提醒我喝水”，小满复述，使用者确认。
5. 到时提醒，按猫爪确认，展示记录。

演示前按完成情况定稿；现场快演可将间隔设置为十秒，并说明实际设置。上海话措辞经本地说话者审校，实时合成与固定录音分别说明。
