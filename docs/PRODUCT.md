# 产品与交互

## 小满的名字

**有伴的日子，刚刚好。**

小满表达对日常生活里小小满足的珍惜。产品希望承载彼此回应的关系：使用者通过抚摸、打招呼与分享日常表达亲近，小满通过声音和动作回应，让每天的相处逐渐变得熟悉。

## 使用者与场景

面向愿意与宠物形态设备互动、愿意尝试语音交流的老年人。前期围绕养老机构使用场景展开思考，原型优先放在茶几、床头或书桌等容易看见和触及的位置，观察触摸和交谈的意愿。

使用者可选择普通话或上海话，设置声音大小、说话速度和主动问候频率。形态、触感和操作方式通过体验反馈调整。

## 三段相处

### 经过时，摸摸它

轻摸头部，小满呼噜，并轻轻动一动。反馈应及时、轻柔，头部触摸区容易找到，底座稳定。首版采用一个简单动作，比较声音与动作时机是否自然。

### 坐下来，聊聊家常

按猫爪开始说话，聊今天吃了什么、天气或个人兴趣。每次表达一两句，留出回答时间。声音采用清楚自然的成年人表达，性格温和、安静，有一点猫的自主感。

普通话先跑通完整流程，再试上海话。方言文案、发音和声音气质交由本地说话者试听审校，分别评价清晰度、自然度和亲切感。

### 生活里的小惦记

使用者说出提醒，小满复述事项与时间，等待确认后建立任务。到时以声音和微动作提醒，按猫爪完成确认。网页保留这次提醒的内容、时间与状态。

对时间含糊的表达，先提出一个简短问题，再执行。重复确认的含义由当前状态决定，防止把同一次按钮操作记到错误任务。

## 形态方向

- 以圆头、短腿与卷尾的坐姿猫形为本轮方向，采用连续柔软的硅胶表皮；头背容易触及，猫爪区域提供清楚的操作入口。姿态通过稳定性和装配验证后确定。
- 内部支架与柔软接触层分开设计，便于装配与维护。
- 硅胶作为外层目标材料，尾巴与身体材质统一；先做局部小样，比较硬度、厚度、内部柔性支撑、轻压变形、回弹、清洁与传感器表现。
- 麦克风、出音孔、散热和静音操作在造型阶段预留。
- 首版选配一个低噪声舵机，控制头部或尾部微动作。
- 当前尺度约28–30厘米高，用桌面与普通水杯作视觉参照；尺寸随可达性和稳定性打样确定。

## 微光、触点与可更换配件

额头、上背与猫爪以同材质浅浮雕提示交互区域，胸腹局部暖光与猫爪边缘微光回应触摸和操作。光线缓入缓出，亮度、夜间行为与关闭由使用者设置。原型先联调猫爪输入和一处灯光。

猫身保持乳白硅胶与琥珀眼睛。可拆洗的番茄红短领巾采用奶油白窄花边，湖蓝浅贝雷帽点缀一枚小花；双耳、额头触点与腹部微光保持可见。奶白小满头像、樱桃包挂与白底花朵杯垫延续相同图案和配色，由长者按个人喜好选配。

拟与养老机构、社区手工坊开展选色、织作、拼豆与试穿共创，作品用途、参与者署名及报酬事先协商。配件版型为触摸、灯光、拾音、出音和散热位置预留空间。详见[微光与长者手作](COCREATION.md)。

## 交互状态草案

| 状态 | 计划反馈 |
| --- | --- |
| 安静 | 保持安静坐姿，降低主动发声频率 |
| 被抚摸 | 呼噜或轻微摆尾 |
| 正在听 | 简短开始提示，保持可辨认的状态 |
| 等待回复 | 轻提示，避免重复催促 |
| 正在说 | 播放回复；按猫爪停止播放并准备下一轮输入，具体行为待联调 |
| 提醒 | 清楚说出事项，等待确认 |
| 静音 | 保留可见状态与触摸反馈，声音行为按设置执行 |

## 后续方向

依据首版反馈完善触感、声音和动作，再评估使用者选择的回忆话题、兴趣偏好和家人留言。保存个人偏好和音频样本前说明用途，提供清除入口；对外演示使用授权素材。

长期关注使用者是否愿意主动亲近、是否理解反馈，以及一段时间后是否仍愿意与小满相处。
